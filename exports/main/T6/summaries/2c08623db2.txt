# **Board Summary: New Branch Rotation and Shelving Procedure Evaluation**

---

## **Bottom Line**

**On average, the new procedure improved service scores by 1.95 points (approximately 4%).** The effect is statistically reliable and the analysis meets key validity checks. However, results varied across branches—about two-thirds saw improvement while one-third did not. **We recommend proceeding with rollout, paired with implementation support to maximize success.**

---

## **Key Findings**

### 1. Average Treatment Effect
| Metric | Value |
|--------|-------|
| Estimated effect | **+1.95 points** |
| 95% Confidence interval | 1.58 to 2.32 points |
| Statistical significance | p < 0.001 |
| Relative improvement | **3.8%** vs. baseline |

### 2. Validity Check: Parallel Trends
A critical assumption for this analysis is that treatment and control branches would have followed similar trends absent the intervention. The pre-switch data (weeks 6-14) supports this:
- **Parallel trends test: p = 0.51** (no significant difference in pre-trends)
- This increases confidence that the estimated effect is causal

### 3. Variation Across Branches
| Outcome | % of Switched Branches |
|---------|----------------------|
| Improved (any gain) | 66% |
| Improved by 2+ points | 45% |
| Declined | 34% |

This variation suggests **implementation quality matters**. The procedure works on average, but not uniformly.

### 4. Comparison Group Context
Branches that did not switch experienced a slight decline (-0.62 points) during the same period. This suggests the new procedure may also help branches **avoid score erosion** that occurred elsewhere.
