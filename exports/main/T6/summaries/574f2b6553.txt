# **Board Summary: New Branch Stock Rotation Procedure Evaluation**

---

## **Bottom Line**

**The new procedure shows evidence of a modest improvement in service scores, but the effect is uncertain.** Our analysis found a statistically significant increase of **1.75 points** (p=0.020), but the 95% confidence interval [0.28, 3.21] indicates the true effect could be as small as 0.3 points or as large as 3.2 points. The board should weigh this uncertain benefit against implementation costs before deciding on system-wide rollout.

---

## **Key Findings**

### **Main Result**

| Metric | Value | Interpretation |
|--------|-------|----------------|
| Estimated effect | **+1.75 points** | Average improvement |
| 95% Confidence interval | **[0.28, 3.21]** | True effect likely in this range |
| p-value | **0.020** | Statistically significant at 5% level |
| Effect size | **0.17 SD** | Small-to-moderate |

### **What This Means**
- **Best case**: ~3.2 point improvement (6% of average score)
- **Most likely**: ~1.75 point improvement (3.3% of average score)  
- **Worst case (still positive)**: ~0.3 point improvement (0.5% of average score)

### **Study Design**
- **34 branches**: 20 switched to new procedure, 14 kept old procedure
- **17 weeks**: Weeks 6–14 (before), Weeks 15–22 (after)
- **Method**: Difference-in-Differences with branch and week fixed effects

### **Validity Assessment**

| Check | Result | Implication |
|-------|--------|-------------|
| Parallel trends (pre-switch) | ✓ Passed (p=0.86) | Groups were comparable before switch |
| Robust to controls | ✓ Effect stable | Not explained by staffing/visits |
| Consistency across weeks | ⚠ 7 of 8 weeks positive | One week showed negative effect |
| Confidence interval | ⚠ Lower bound near zero | Effect could be very small |

## **Next Steps**

### **Decision Framework**
The board should consider:

1. **Implementation costs**: Training, temporary disruption, staff time
2. **Minimum worthwhile effect**: What improvement justifies the cost?
3. **Risk tolerance**: Are you comfortable with the possibility the true effect is near zero?

### **Recommended Actions**

**If proceeding with rollout:**
- Phase implementation to monitor results at each stage
- Set clear success metrics (e.g., minimum 1.0 point improvement)
- Be prepared to adjust or halt if results don't materialize

**If seeking more certainty:**
- Extend the observation period to reduce uncertainty
- Consider a randomized rollout to strengthen causal inference
- Pilot at a few more branches before system-wide commitment

### **Expected Outcome**
If the estimated effect holds, system-wide scores would rise from ~53 to ~55 points. However, given the confidence interval, the actual improvement could range from negligible (~0.3 points) to meaningful (~3 points).
