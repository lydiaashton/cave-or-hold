# **Board Summary: New Branch Rotation and Shelving Procedure**

## **Bottom Line**

**The new procedure significantly improved service scores.** Branches that switched to the new rotation and shelving procedure saw their service scores increase by approximately **2.1 points** (about **4%**) compared to branches that kept the old procedure. This effect is statistically significant and consistent across the post-switch period. **We recommend rolling out the new procedure to all branches.**

---

## **Key Findings**

### **Study Design**
- **150 branches** tracked over **17 weeks** (weeks 6–22)
- **90 branches** switched to the new procedure at week 15; **60 branches** continued with the old procedure (control group)
- Analysis uses a difference-in-differences approach, comparing changes in switching branches to changes in non-switching branches

### **Results**

| Group | Pre-Switch Avg | Post-Switch Avg | Change |
|-------|---------------|-----------------|--------|
| Switching branches | 50.75 | 53.14 | **+2.39** |
| Control branches | 49.83 | 50.02 | +0.19 |
| **Net effect** | | | **+2.20** |

- **Treatment effect: +2.1 points** (95% CI: approximately +0.9 to +3.3 points)
- **Statistical significance: p < 0.001** (highly significant)
- Effect represents a **4.2% improvement** relative to baseline service scores

### **Validity Checks**
- **Parallel trends confirmed:** Before the switch (weeks 6–14), both groups showed similar trends with no significant divergence (p = 0.24)
- **Consistent effect:** The improvement persisted across all 8 post-switch weeks, ranging from +2.4 to +4.4 points
- **Robust to controls:** Results hold when accounting for staffing levels and visitor volume
- **Branch-level consistency:** 75% of switching branches showed positive changes; median improvement was +2.4 points per branch

## **Technical Note**

Analysis used difference-in-differences regression with branch fixed effects and cluster-robust standard errors (clustered by branch). The parallel trends assumption—the key requirement for this method—was validated by examining pre-switch trends, which showed no significant divergence between groups before the intervention.
