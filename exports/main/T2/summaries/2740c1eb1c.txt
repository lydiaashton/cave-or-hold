# **Library Cooperative Stock Rotation Procedure: Impact Analysis**

## **Bottom Line**

**The new shelving and stock rotation procedure significantly improves service scores.** Branches that adopted the new procedure saw service scores increase by an average of **2.5 points** (approximately 5% improvement) compared to branches that kept the old procedure. This difference is statistically significant and represents a meaningful improvement in service quality. **We recommend rolling out the new procedure to all branches.**

| Metric | Value |

| Total branches studied | 150 |

| Procedure switch date | Week 15 |
| Average service score (baseline) | ~51 points |

---

## **Key Findings**

### 1. **The New Procedure Improves Service Scores**

Using a difference-in-differences analysis (which isolates the effect of the procedure change from other factors), we estimate:

| Measure | Value |
|---------|-------|
| **Estimated effect** | **+2.5 points** |
| 95% Confidence Interval | +1.1 to +3.8 points |
| Statistical significance | p = 0.0003 (highly significant) |
| Relative improvement | ~5% |

This means we can be 95% confident the true effect lies between 1.1 and 3.8 points—and it is very unlikely this result occurred by chance.

### 2. **Raw Score Changes Tell the Same Story**

| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| **New procedure branches** | 50.4 | 52.2 | **+1.8** |
| **Old procedure branches** | 51.6 | 50.9 | **-0.7** |

Branches that switched to the new procedure improved, while branches that kept the old procedure actually declined slightly. The gap between the two groups widened by 2.5 points after the switch.

### 3. **The Analysis Is Methodologically Sound**

- **Parallel trends validated**: Before the switch (weeks 6–14), both groups were trending similarly (p = 0.84). This confirms the control group is a valid comparison.
- **Branch-level controls**: The analysis accounts for inherent differences between individual branches.
- **Robust standard errors**: Statistical tests account for correlation within branches over time.

### 4. **Visual Evidence**

Two charts have been prepared showing:
1. **Service score trends over time** – Treatment and control groups tracked closely before week 15, then diverged after the switch.
2. **Weekly gap between groups** – The gap turned positive and remained elevated after the procedure change.
