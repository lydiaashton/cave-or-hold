# **Board Summary: New Branch Rotation and Shelving Procedure Evaluation**

## **Bottom Line**

**Yes, the new procedure improved service scores.** Branches that switched to the new rotation and shelving procedure saw service scores increase by **1.9 points** (95% CI: 1.2 to 2.6) compared to branches that kept the old procedure. This represents a **3.8% improvement** over the average service score of 51. The effect is statistically significant (p < 0.001) and the recommendation is to **proceed with system-wide rollout**.

---

## **Key Findings**

### 1. Treatment Effect
- The new procedure is associated with a **+1.9 point increase** in weekly service scores
- This effect is **highly statistically significant** (p < 0.001)
- The 95% confidence interval ranges from **1.2 to 2.6 points**, indicating the true effect is very likely positive

### 2. What the Data Shows
| Group | Before Switch (Weeks 6-14) | After Switch (Weeks 15-22) | Change |
|-------|---------------------------|---------------------------|--------|
| Control (old procedure) | 48.9 | 50.9 | +2.0 |
| Treated (new procedure) | 49.6 | 53.5 | +3.9 |
| **Difference** | | | **+1.9** |

Both groups improved after week 15, but branches using the new procedure improved **nearly twice as much** as those using the old procedure.

### 3. Robustness Checks
- The result **holds when controlling for** weekly staffing levels and visit volumes
- The effect is **consistent across the 8-week post-switch period**, with benefits appearing to grow over time
- **425 branches** (60%) adopted the new procedure; **284 branches** (40%) served as controls

### 4. Validity of the Analysis
- The parallel trends assumption (required for this type of analysis) appears reasonable: there was no statistically significant difference in how the two groups were trending before the switch (p = 0.06)
- The analysis uses **12,053 weekly observations** across **709 branches** over **17 weeks**, providing strong statistical power

## **Analytical Note**

This analysis uses a difference-in-differences approach, which compares the change in service scores for branches that switched procedures against the change for branches that did not. This method isolates the effect of the new procedure from other factors (such as seasonal changes or system-wide initiatives) that affected all branches during the same period.
