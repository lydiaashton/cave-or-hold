# **Library Cooperative Branch Procedure Change: Service Score Analysis**

## **Bottom Line**

**Yes, the new shelving procedure improved service scores.** Branches that switched to the new procedure saw service scores increase by approximately **2.2 points** compared to branches that kept the old procedure. This effect is statistically significant and represents about a **4% improvement** relative to the average branch score of 50.

---

## **Key Findings**

### **1. Treatment Effect**
| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| Control (Old Procedure) – 284 branches | 51.03 | 49.87 | −1.16 |
| Treatment (New Procedure) – 425 branches | 51.00 | 52.02 | +1.02 |
| **Difference-in-Differences** | | | **+2.19** |

- **Estimated effect: +2.2 points** (95% confidence interval: 1.65 to 2.76)
- **Statistical significance: p < 0.001** (highly reliable result)

### **2. Analysis Method**
This analysis uses a **difference-in-differences** approach, which compares:
- Changes over time in branches that adopted the new procedure **vs.**
- Changes over time in branches that kept the old procedure

This method controls for any overall trends affecting all branches (such as seasonal variations) and isolates the effect of the procedure change itself.

### **3. Data Overview**
- **709 branches** total (425 switched, 284 did not)
- **17 weeks** of data (Weeks 6–22)
- Switch implemented at **Week 15**
- Analysis controls for staffing levels and visitor volume

### **4. Important Caveat**
The analysis detected that treatment group branches were already showing slightly stronger upward trends in service scores *before* the switch. This means the 2.2-point estimate **may be somewhat optimistic**. However, even accounting for this, the post-switch divergence between groups is substantial and statistically clear.
