# **Library Branch Procedure Change: Impact on Service Scores**

## **Bottom Line**

**Yes, the new procedure improved service scores.** Branches that switched to the new procedure saw a statistically significant increase of **2.16 points** (approximately **4.4% improvement**) in their service scores compared to branches that kept the old procedure. We recommend rolling out the new procedure to all branches.

---

## **Key Findings**

### 1. Study Design & Data
- **709 branches** analyzed over **17 weeks** (Weeks 6–22)
- **425 branches** adopted the new procedure (treatment group)
- **284 branches** kept the old procedure (control group)
- The switch occurred at **Week 15**, providing 9 weeks of "before" data and 8 weeks of "after" data

### 2. Main Result: The New Procedure Works
Using a difference-in-differences analysis (the gold standard for this type of evaluation), we found:

| Metric | Value |
|--------|-------|
| **Effect Size** | +2.16 service score points |
| **95% Confidence Interval** | [1.60, 2.71] |
| **Statistical Significance** | p < 0.001 (highly significant) |
| **Percentage Improvement** | 4.4% over baseline |

This means the improvement is very unlikely to be due to random chance, and we can be 95% confident the true effect lies between 1.6 and 2.7 points.

### 3. Branch-Level Outcomes
- **80.5%** of branches using the new procedure saw their scores improve
- Only **62.0%** of branches using the old procedure saw improvement
- This 18.5 percentage point gap confirms the new procedure benefits most branches

### 4. Parallel Trends Check (Validity Test)
Before the switch, both groups had similar score trajectories (average difference of only 0.6 points), confirming the comparison is valid. The divergence after Week 15 is attributable to the procedure change.

### 5. Visual Evidence
The attached charts show:
- **Trend chart**: Treatment and control groups tracked closely before Week 15, then the treatment group pulled away afterward
- **Distribution chart**: Treatment branches cluster around higher score changes than control branches

## **Methodology Note**

This analysis uses a **difference-in-differences** approach with branch fixed effects and clustered standard errors, which accounts for:
- Time-invariant differences between branches
- System-wide trends affecting all branches
- Correlation in repeated observations of the same branch

This is the same methodology used in peer-reviewed policy evaluations and provides robust causal evidence.
