# Analysis of New Branch Stock Rotation Procedure

## Bottom Line

**The new procedure improved service scores.** Branches that adopted the new rotation and shelving procedure saw service scores increase by approximately **2 points (4%)** compared to branches that kept the old procedure. This effect is statistically significant (p=0.002), and we can be confident the improvement is real and not due to random variation.

**Recommendation:** Proceed with rolling out the new procedure to all branches.

---

## Key Findings

### 1. Measurable Improvement in Service Scores
- Branches using the new procedure improved by **+1.99 points** on the service score index relative to branches using the old procedure
- 95% confidence interval: **0.71 to 3.26 points** (the true effect is very likely positive)
- This represents approximately a **4% improvement** over the baseline average score of 50.6

### 2. Strong Statistical Evidence
- The result is highly statistically significant (p=0.002)
- Analysis controlled for other factors like staffing levels and visitor volume, which did not explain the improvement
- Standard errors were adjusted to account for repeated measurements at each branch, making the test conservative

### 3. Valid Comparison Between Groups
- Before the switch (weeks 6-14), both groups followed parallel trends—there was no systematic difference in how their scores were changing over time
- This supports the conclusion that the observed improvement is due to the new procedure, not pre-existing differences between branches

### 4. Consistent Positive Pattern
- 57% of branches using the new procedure saw their scores improve after the switch
- Only 45% of branches using the old procedure saw improvement during the same period
- The average branch using the old procedure actually saw scores decline slightly (-0.49 points)

## Methodology Note

This analysis used a **difference-in-differences** approach, comparing the change in service scores for branches that switched to the new procedure against the change for branches that kept the old procedure. This method isolates the effect of the procedure change from other factors that might affect all branches simultaneously (such as seasonal patterns or system-wide initiatives). The analysis included 2,550 weekly observations from 150 branches over 17 weeks (weeks 6-22), with the switch occurring in week 15.
