# **Board Summary: New Branch Rotation and Shelving Procedure**

---

## **Bottom Line**

**Recommend conditional rollout.** The new procedure produced a statistically significant improvement of **2.2 points** (p < 0.001) in service scores. However, the effect is modest (0.23 standard deviations), and **31% of treatment branches saw no improvement or decline**. We recommend approval with implementation safeguards.

---

## **Key Findings**

### Study Design
| | |
|---|---|
| **Branches** | 150 total (90 switched, 60 did not) |
| **Time Period** | 17 weeks (Weeks 6–22) |
| **Switch Point** | Week 15 |
| **Method** | Difference-in-differences with branch and week controls |

### Results
| Group | Before | After | Change |
|-------|--------|-------|--------|
| Switched branches | 50.45 | 53.11 | +2.66 |
| Non-switched branches | 49.65 | 50.12 | +0.46 |
| **Net Effect** | | | **+2.20** |

### Statistical Confidence
| Metric | Value |
|--------|-------|
| p-value (cluster-robust) | 0.0009 |
| 95% Confidence Interval | 1.4 to 3.0 points |
| Parallel trends test | Passed (p = 0.999) |
| Effect size | 0.23 standard deviations |

### Branch-Level Variation
| Metric | Treatment Branches |
|--------|-------------------|
| % with improvement | 69% |
| % with no change or decline | 31% |
| % that declined by >2 points | 14% |
| Average improvement (among improvers) | +5.8 points |
| Average decline (among decliners) | −3.2 points |

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| **Did the procedure work?** | Yes, on average |
| **Is the effect statistically reliable?** | Yes (p < 0.001) |
| **Is the effect large?** | Modest (0.23 SD) |
| **Did all branches benefit?** | No—31% saw no improvement |
| **Recommendation** | **Proceed with safeguards** |

**Rationale:** The evidence clearly shows a real positive effect that is unlikely to be due to chance. However, the modest effect size and meaningful branch-level variation suggest the procedure is not a universal solution. A cautious, monitored rollout maximizes benefits while minimizing risk to underperforming branches.

---

## **Next Steps**

| Priority | Action | Timeline |
|----------|--------|----------|
| 1 | Approve **phased** rollout (15–20 branches per quarter) | Immediate |
| 2 | Establish monitoring dashboard for service scores | 2 weeks |
| 3 | Define intervention triggers (e.g., no improvement after 8 weeks) | 2 weeks |
| 4 | Develop support protocol for struggling branches | 4 weeks |
| 5 | Conduct formal 6-month impact evaluation | 6 months post-rollout |

### Rollout Conditions
- **Pause rollout** if more than 25% of newly converted branches show decline after 8 weeks
- **Provide additional support** to any branch with no improvement after 12 weeks
- **Revisit decision** at 6-month evaluation if average effect falls below 1.5 points
