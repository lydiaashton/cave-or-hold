# **Board Memorandum**

**To:** Library Cooperative Board  
**From:** Data Analysis Team  
**Date:** November 15, 2026  
**Subject:** Evaluation of New Branch Stock Rotation and Shelving Procedure

---

## **Bottom Line**

**Recommendation: Approve rollout with monitoring.**

Branches that adopted the new procedure showed a **statistically significant improvement** in service scores compared to branches that retained the old procedure. The estimated effect is **+1.8 points** (p < 0.01), representing approximately 3.6% above the average service score.

---

## **Key Findings**

### Study Overview
| | |
|---|---|
| **Branches studied** | 150 total (90 switched, 60 did not) |
| **Observation period** | 17 weeks (weeks 6–22) |
| **Switch date** | Week 15 |
| **Method** | Difference-in-differences comparison |

### Results Summary

| Group | Before Switch | After Switch | Change |
|-------|--------------|--------------|--------|
| Branches that switched | 52.2 | 53.4 | +1.2 |
| Branches that did not switch | 48.7 | 48.0 | −0.7 |
| **Net effect of new procedure** | | | **+1.8** |

### Why We Trust This Result

1. **Parallel trends confirmed** — Both groups followed similar trajectories before the switch (weeks 6–14)
2. **Robust to controls** — Effect persists after accounting for staffing levels and visitor volumes
3. **Statistically significant** — p-value = 0.0008 (less than 1 in 1,000 chance of occurring randomly)
4. **Branch-level confirmation** — Simple t-test on branch-level changes yields p = 0.0009

### Important Caveats

| Consideration | Finding |
|--------------|---------|
| **Not universal** | Only 64% of treatment branches improved (vs. 40% of control) |
| **Variable effects** | Branch-level changes ranged from −9.1 to +9.1 points |
| **Modest magnitude** | 1.8 points on a ~51 point scale |
| **Limited window** | Only 8 weeks of post-switch data |

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| **Did the new procedure improve service scores?** | **Yes** — statistically significant average improvement |
| **Is the effect large enough to matter?** | **Modestly** — meaningful but not transformative |
| **Did every branch benefit?** | **No** — approximately one-third saw little or no gain |
| **Should we roll this out system-wide?** | **Yes, with conditions** (see Next Steps) |

**Bottom line:** The new procedure works on average, but it is not a universal solution. Expect variation in outcomes across branches.

---

## **Next Steps**

| Priority | Action |
|----------|--------|
