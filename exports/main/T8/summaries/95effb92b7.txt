# **Evaluation of New Branch Stock Rotation Procedure**

---

## **Bottom Line**

**The new procedure protected against service score declines.** After the switch, all branches saw scores fall (likely due to seasonal or system-wide factors). However, branches using the new procedure declined **2.0 points less** than those using the old procedure. This buffering effect is statistically significant (p < 0.001). 

**Recommendation:** Proceed with rollout, but set realistic expectations—the new procedure helps maintain service levels during downturns rather than raising them.

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| Did the new procedure change service scores? | **Yes** |
| Did it improve absolute scores? | **No** — all branches declined |
| Did it provide a relative benefit? | **Yes** — 2.0 points of protection |
| Is the effect statistically reliable? | **Yes** — p < 0.001 |
| **Should we roll out to all branches?** | **YES** |

**Rationale:** The new procedure delivers a consistent, measurable benefit. While it does not raise service scores in absolute terms, it meaningfully cushions branches against declines. In a period where non-switched branches lost 3.1 points, switched branches lost only 1.1 points. This preservation of service quality justifies system-wide adoption.

## **Key Findings**

### **What Actually Happened to Scores**

| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| Switched branches | 55.24 | 54.11 | **−1.12** |
| Non-switched branches | 53.12 | 50.01 | **−3.11** |
| **Difference-in-Differences** | | | **+1.98** |

Both groups declined. The new procedure's benefit is that switched branches fell **less**.

### **Why This Still Matters**
- Without the new procedure, switched branches would likely have dropped ~3 points (like control branches) instead of ~1 point
- The 2-point buffering effect represents meaningful service preservation during what appears to be a challenging period
- Effect is consistent across all 8 post-switch weeks

### **Validity Checks**
- **Parallel trends confirmed**: Pre-switch trends were statistically indistinguishable (p = 0.74)
- **Consistent effects**: Positive buffering observed in every post-switch week
- **Robust to controls**: Results hold accounting for branch characteristics, week effects, staffing, and visits
