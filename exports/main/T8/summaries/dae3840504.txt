# **MEMORANDUM TO THE BOARD**

---

## **Title: Impact of New Shelving Procedure on Branch Service Scores**

**Date:** November 15, 2026  
**Subject:** Recommendation on System-Wide Rollout of New Shelving Procedure

---

## **Bottom Line**

**The new shelving procedure produced a statistically significant improvement in service scores (+1.76 points, p=0.002). The effect is modest but real and consistent.** We recommend proceeding with rollout, provided implementation costs are reasonable.

---

## **Key Findings**

### Study Overview
- **150 branches** participated: 90 adopted the new procedure, 60 continued with the old procedure
- **17 weeks of data** (weeks 6–22), with the change implemented at week 15
- Analysis used a **difference-in-differences** approach to isolate the procedure's effect

### Results Summary

| Metric | Value |
|--------|-------|
| Estimated improvement from new procedure | **+1.76 points** |
| 95% Confidence Interval | **0.66 to 2.87 points** |
| Statistical Significance | **p = 0.002** |
| Relative Improvement | **~3.5%** |
| Effect Size (Cohen's d) | **0.18** (small) |

### Why We Trust These Results

1. **Comparable groups before the switch**: Service score trends were nearly identical for both groups during weeks 6–14.

2. **Consistent effects after implementation**: Branches using the new procedure outperformed control branches in **all 8 weeks** following the switch.

3. **No confounding factors**: Staffing levels and visitor volumes were balanced between groups.

4. **Rigorous statistical methods**: Analysis used cluster-robust standard errors to account for repeated measurements.

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| Did the procedure change service scores? | **Yes** — the effect is statistically significant |
| Is the effect meaningful? | **Modestly** — 3.5% improvement, small effect size |
| Was our original expectation correct? | **No** — we expected no difference; the data shows otherwise |
| Should we roll out system-wide? | **Yes, with conditions** — proceed if implementation costs are low |

**Rationale:** The data provides clear evidence that the new procedure improves service scores. While the magnitude is modest, the effect is:
- **Reliable** (significant at the 1% level)
- **Consistent** (positive in every post-switch week)
- **Cost-free to test** (the 90 branches already implemented it)

The main risk is not effectiveness—it's **implementation cost**. If rolling out to the remaining 60 branches requires substantial training, staff time, or equipment, the board should weigh whether a 3.5% service improvement justifies that investment. If costs are minimal, rollout is recommended.
