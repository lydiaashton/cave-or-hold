# **Impact of New Branch Rotation and Shelving Procedure on Service Scores**

**Date:** November 15, 2026  
**Prepared for:** Library Cooperative Board  
**Analysis Period:** Weeks 6-22 (17 weeks of data from 150 branches)

---

## **Bottom Line**

**The new procedure significantly improved service scores.** Branches that adopted the new rotation and shelving procedure experienced a **2-point increase** in service scores compared to branches that retained the old procedure. This effect is statistically significant (p < 0.01) and represents approximately a **4% improvement** relative to the typical branch score of 50.

**Recommendation:** Proceed with rolling out the new procedure to all branches.

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| Did the new procedure change service scores? | **Yes** — positive effect confirmed |
| Is the result statistically reliable? | **Yes** — p = 0.001, robust across models |
| Is the effect large enough to matter? | **Yes** — 4% improvement is meaningful for patrons |
| Should we roll out to all branches? | **Yes** — evidence supports system-wide adoption |

**Confidence Level:** High. The analysis meets standard criteria for causal inference: (1) clear treatment and control groups, (2) parallel pre-trends, (3) statistically significant effect, (4) consistent results across specifications, and (5) persistent effect across all post-switch weeks.

**Caveat:** The true effect likely falls between 0.8 and 3.3 points. Additionally, part of the measured effect reflects a decline in control branch scores during the same period, which warrants monitoring but does not undermine the conclusion that the new procedure benefited adopting branches.

---

## **Key Findings**

### 1. Clear Positive Impact from the New Procedure

| Group | Before Switch (Weeks 6-14) | After Switch (Weeks 15-22) | Change |
|-------|---------------------------|---------------------------|--------|
| Control branches (old procedure) | 52.12 | 51.20 | −0.91 |
| Treatment branches (new procedure) | 51.42 | 52.55 | +1.14 |
| **Net Effect (Difference-in-Differences)** | | | **+2.05** |

Branches using the new procedure improved by 1.14 points, while control branches declined by 0.91 points. The net effect of **+2.05 points** isolates the impact of the procedure change itself.

### 2. Results Are Statistically Robust

The finding holds consistently across multiple analytical approaches:

| Model Specification | Estimated Effect | P-value |
|--------------------|------------------|---------|
| Basic difference-in-differences | +2.05 points | 0.001 |
| With staffing and visitor controls | +2.04 points | 0.001 |
| With branch fixed effects | +2.03 points | 0.001 |

All models use cluster-robust standard errors to account for repeated observations within branches.

### 3. Pre-Switch Trends Validate the Analysis

Service score trends for both groups were parallel before the switch (weeks 6-14), with no systematic divergence (pre-trend test: p = 0.57). This supports the validity of the difference-in-differences approach and strengthens confidence that the observed effect is attributable to the procedure change rather than pre-existing differences between branches.

### 4. Effect Is Meaningful for Patrons

A 2-point improvement on a scale where the average branch scores about 50 represents a **4% gain in service quality**. This is a practically significant improvement that patrons should notice in their library experience.

## **Technical Notes**

- **Data:** 2,550 weekly observations from 150 branches (60 control, 90 treatment)
- **Method:** Difference-in-differences regression with cluster-robust standard errors
- **Controls:** Staffing index and visits index (both positively associated with service scores)
- **Validation:** Pre-trend analysis confirms parallel trends before the switch (p = 0.57)
- **95% Confidence Interval:** 0.83 to 3.27 points
