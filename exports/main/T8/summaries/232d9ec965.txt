# **Board Memorandum**

**To:** Library Cooperative Board  
**From:** Data Analysis Team  
**Date:** November 2025  
**Subject:** Evaluation of New Branch Rotation and Shelving Procedure  

---

## **Bottom Line**

**The new procedure improved service scores by 2 points.** This was unexpected—we anticipated no measurable change—but the data are clear and statistically robust. We recommend proceeding with system-wide rollout.

---

## **The Evidence**

| Metric | Value |
|--------|-------|
| Treatment effect | **+2.1 points** |
| 95% Confidence interval | **1.0 to 3.3 points** |
| Statistical significance | **p = 0.0002** |
| Effect size | **~4% improvement** |

**What happened:**
- Switched branches: 52.6 → 53.9 (+1.3)
- Non-switched branches: 52.0 → 51.2 (–0.9)
- **Net benefit of switching: +2.1 points**

---

## **Why This Finding Is Credible**

1. **Clean comparison**: 90 branches switched, 60 did not—creating a natural control group
2. **Parallel trends confirmed**: Pre-switch trajectories were statistically identical (p = 0.93)
3. **Consistent effect**: All 8 post-switch weeks showed positive effects; none showed decline
4. **Robust to controls**: Result holds accounting for staffing and visitor volume

---

## **Final Verdict**

| | |
|---|---|
| **Recommendation** | **ROLL OUT TO ALL BRANCHES** |
| **Confidence Level** | **High** |
| **Expected Impact** | **+2 points on service score index** |
| **Risk Assessment** | **Low — no adverse effects detected** |

**Rationale:** The analysis meets all standards for causal inference. The treatment effect is statistically significant, practically meaningful, and consistent across the observation period. Despite initial expectations that the procedure change would have no effect, the evidence demonstrates clear benefit. Delaying rollout would deny patrons improved service at branches still using the old procedure.

---

## **Next Steps**

1. **Board vote** on system-wide adoption
2. **Implementation timeline**: 4–6 week phased rollout
3. **Training**: Prepare materials for switching branches
4. **Monitoring**: Track service scores for 12 weeks post-rollout
