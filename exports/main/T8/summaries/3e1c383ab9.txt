# **MEMORANDUM**

**TO:** Board of Directors, Library Cooperative  
**FROM:** Data Analysis Team  
**DATE:** November 15, 2026  
**SUBJECT:** Evaluation of New Branch Rotation and Shelving Procedure  

---

## **Bottom Line**

**The data indicates the new procedure improved service scores.** Branches that adopted the new procedure achieved service scores approximately **2.1 points higher** than would be expected based on trends in branches that kept the old procedure. The effect is statistically significant (p < 0.01) and the 95% confidence interval excludes zero. **We recommend proceeding with rollout, with continued monitoring to confirm the effect persists at scale.**

---

## **Key Findings**

### Analysis Overview
- **150 branches**: 90 adopted the new procedure, 60 retained the old
- **17 weeks** of data (weeks 6-22), switch occurred at week 15
- Method: Difference-in-differences analysis with clustered standard errors

### Results Summary

| Group | Before (Weeks 6-14) | After (Weeks 15-22) | Change |
|-------|---------------------|---------------------|--------|
| Branches that switched | 53.6 | 54.4 | +0.8 |
| Branches that did not switch | 53.3 | 51.9 | -1.3 |
| **Estimated effect of new procedure** | | | **+2.1** |

### Statistical Evidence
- **Effect estimate:** +2.11 points (95% CI: 0.87 to 3.36)
- **P-value:** 0.0009 (less than 1% probability this is due to chance)
- **Practical significance:** ~4% improvement relative to baseline; approximately 0.22 standard deviations
- **Robustness:** Effect persists after controlling for staffing levels and visitor volume

### Validity Checks
- **Parallel trends verified:** No statistically significant difference in pre-switch trends between groups (p = 0.36)
- **Clustered standard errors:** Account for repeated observations per branch
- **Note:** This is observational data; branches were not randomly assigned to switch

---

## **Final Verdict**

| | |
|---|---|
| **Did the new procedure change service scores?** | **Yes** |
| **Direction of effect** | Positive (improvement) |
| **Statistical confidence** | High (p < 0.01) |
| **Practical significance** | Modest but meaningful |
| **Recommendation** | **Proceed with system-wide rollout** |

---

## **Next Steps**

1. **Roll out** the new procedure to remaining 60 branches
2. **Track** service scores for 8-12 weeks post-implementation at each branch
3. **Document** implementation practices from early-adopter branches
4. **Reconvene** in one quarter to review rollout outcomes and confirm expected benefits

---

*This analysis contradicts the prior expectation that the procedure change would have no effect. The data provides statistically significant evidence of improvement, though continued monitoring is warranted given the observational nature of the study.*
