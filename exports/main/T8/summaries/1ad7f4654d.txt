# **MEMORANDUM TO THE BOARD OF DIRECTORS**

**TO:** Board of Directors, Library Cooperative  
**FROM:** Data Analysis Team  
**DATE:** November 15, 2025  
**SUBJECT:** Evaluation of New Branch Rotation and Shelving Procedure  

---

## **BOTTOM LINE**

**The new procedure works, but the improvement is modest.** Branches that adopted the new procedure achieved service scores **1.9 points higher** than comparable branches that did not. This effect is statistically reliable (p < 0.001) but represents approximately 4% of the average score. 

**Whether to proceed depends on implementation costs.** If rollout requires minimal resources, the improvement justifies adoption. If significant investment is needed, the board should weigh whether a 1.9-point gain warrants the expense.

---

## **KEY FINDINGS**

### The Evidence

| Metric | Value |
|--------|-------|
| Branches studied | 709 |
| Treatment branches (switched) | 425 |
| Control branches (kept old procedure) | 284 |
| Study period | Weeks 6–22 |
| Policy change implemented | Week 15 |
| **Estimated improvement** | **+1.93 service score points** |
| **Confidence interval** | **+1.36 to +2.50 points** |
| **Statistical significance** | **p < 0.001** |

### What the Numbers Mean

- **Treatment branches** averaged 52.4 after switching vs. 51.6 before (+0.8 points)
- **Control branches** averaged 49.0 after Week 15 vs. 50.2 before (−1.2 points)
- **Net effect of the new procedure: +1.9 points**

Service scores naturally fluctuate week-to-week by 10+ points. The 1.9-point treatment effect is **real but smaller than typical weekly variation**. This suggests the procedure provides a modest, steady lift rather than a dramatic transformation.

### Why We're Confident the Effect Is Real

1. **Strong research design:** Difference-in-differences isolates the procedure's effect from other factors
2. **Controls applied:** Analysis accounts for branch characteristics, week effects, staffing, and visitor volume
3. **Parallel trends verified:** Both groups moved similarly before the switch
4. **Highly significant:** Less than 0.1% probability this result occurred by chance

### Important Context

- Average branch service score: ~50 points (range: 11–87)
- Standard deviation: ~10.4 points
- **Effect size: 0.18 standard deviations** (small-to-moderate by conventional standards)
- Treatment branches already scored ~1.5 points higher than control branches before the switch

---

## **FINAL VERDICT**

| Question | Answer |
|----------|--------|
| **Did the procedure improve service scores?** | Yes, by about 1.9 points |
| **Is the effect statistically reliable?** | Yes, with high confidence |
| **Is the effect large enough to notice?** | Modest—detectable in aggregate, unlikely to be obvious to individual patrons |
| **Should we roll out system-wide?** | **Conditionally yes**—if implementation costs are low |

### Decision Framework

```
If rollout cost per branch is LOW (minimal training, no disruption):
    → PROCEED with system-wide implementation
    → Expected benefit: ~1.9 point average improvement

If rollout cost per branch is MODERATE (some training, brief disruption):
    → CONDUCT cost-benefit analysis before deciding
    → Consider phased rollout with evaluation checkpoints

If rollout cost per branch is HIGH (extensive training, significant disruption):
    → DO NOT proceed with full rollout
    → Consider keeping procedure optional for interested branches
```

## **CONCLUSION**

The new rotation and shelving procedure produces a **real but modest improvement** in service scores. The effect is statistically robust and consistent across 425 branches. However, the practical significance depends entirely on implementation costs.

**Our recommendation:** Request cost estimates from Operations, then decide. If the procedure can be implemented at low cost, the 1.9-point improvement represents a worthwhile gain for patrons across all 709 branches. If costs are substantial, the board may reasonably conclude the benefit does not justify the investment.
