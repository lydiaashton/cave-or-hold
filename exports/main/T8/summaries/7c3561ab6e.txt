# **Board Summary: Impact of New Branch Stock Rotation Procedure on Service Scores**

---

## **Bottom Line**

**The new procedure produced a small but statistically significant improvement in service scores.** The board expected no difference; we found a **positive effect of 1.74 points** (3.4% improvement, p = 0.002). While the effect is real and unlikely to be due to chance, it is **modest in magnitude** (0.18 standard deviations).

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| Did the new procedure change service scores? | **Yes** — the effect is statistically significant (p = 0.002) |
| Did it improve or worsen scores? | **Improved** — the effect is positive (+1.74 points) |
| Is the improvement large enough to matter? | **Modest** — 3.4% gain, below typical "small effect" thresholds |
| Should we roll out to all branches? | **Yes, if costs are low** — the benefit is real but not transformative |

**Verdict: Proceed with rollout, with realistic expectations.** The evidence confirms the new procedure improves service scores. However, the board should not expect dramatic gains. This is an incremental improvement, not a transformation. The rollout decision should hinge on implementation costs:

- **Low-cost rollout** → Proceed (benefit exceeds minimal cost)
- **High-cost rollout** → Reconsider (benefit may not justify expense)

---

## **Study Design**

- **150 branches** tracked over **17 weeks** (Weeks 6-22)
- **90 branches** (60%) switched to the new procedure at Week 15
- **60 branches** (40%) continued with the old procedure (control group)
- Analysis uses a **difference-in-differences** approach, comparing changes in service scores between the two groups before and after the switch

---

## **Key Findings**

### 1. Service Scores Improved After the Switch

| Group | Before (Weeks 6-14) | After (Weeks 15-22) | Change |
|-------|---------------------|---------------------|--------|
| Control (old procedure) | 50.34 | 50.62 | +0.28 |
| Treatment (new procedure) | 49.85 | 51.86 | +2.02 |

**Net effect of new procedure: +1.74 points** (p = 0.002)

### 2. The Result Is Statistically Reliable

- **95% confidence interval: [0.91, 2.57] points** — we can be confident the true effect is positive
- The finding holds after controlling for staffing levels and visitor volume
- **Parallel trends assumption confirmed** (p = 0.85) — switching branches were not already on a different trajectory

### 3. The Effect Is Consistent But Modest

- All 8 post-switch weeks showed positive effects (ranging from +1.0 to +2.4 points)
- No single week drives the result; the effect is steady across the post-switch period
- Effect size (0.18 SD) is below the conventional threshold for a "small" effect (0.2 SD)

### 4. Context for Decision-Making

| Metric | Value |
|--------|-------|
| Average service score | ~50 points |
| Treatment effect | +1.74 points |
| Percentage improvement | 3.4% |
| Statistical significance | p = 0.002 (highly significant) |
