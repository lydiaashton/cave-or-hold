# **MEMORANDUM TO THE BOARD**

---

## **Subject: Impact of New Branch Rotation and Shelving Procedure on Service Scores**

---

## **BOTTOM LINE**

**The new procedure is associated with higher service scores, but with important caveats.** Branches that switched to the new procedure showed service scores approximately **2 points higher** than expected based on control branch trends. This result is statistically significant.

**However**, the treatment branches already scored higher than control branches before the switch, which introduces uncertainty about whether the full effect is due to the procedure itself. 

**Recommendation**: Proceed with **cautious, phased rollout** while continuing to monitor results. The evidence suggests benefit, but we should verify the effect holds as more branches adopt the procedure.

---

## **KEY FINDINGS**

### **Analysis Overview**
| | |
|---|---|
| Branches analyzed | 150 |
| Switched to new procedure | 90 branches |
| Remained on old procedure | 60 branches (control) |
| Observation period | 17 weeks (weeks 6–22) |

### **What the Data Shows**
| Metric | Value |
|--------|-------|
| Estimated improvement | **+2.1 points** |
| Statistical significance | **p < 0.001** |
| 95% Confidence range | 0.9 to 3.2 points |
| Relative gain | **~4%** above baseline |

### **Important Context**

| Consideration | What It Means |
|---------------|---------------|
| **Baseline differences** | Treatment branches scored 1.4 points higher than control branches *before* the switch. The DiD method adjusts for this, but it adds uncertainty. |
| **Effect size** | A 2-point gain is meaningful (about 40% of typical week-to-week variation within a branch) but not transformative. |
| **Limited follow-up** | Only 8 weeks of post-switch data. We don't know if effects persist long-term. |
| **Consistent direction** | The effect was present in both early and late post-switch periods, which is encouraging. |

---

## **FINAL VERDICT**

| Question | Answer |
|----------|--------|
| **Did the new procedure change service scores?** | **Yes** — the data shows a statistically significant improvement. |
| **Can we attribute the full effect to the procedure?** | **Probably, but not certainly** — baseline differences between groups introduce some doubt. |
| **Should we roll out to all branches immediately?** | **No** — the evidence supports adoption, but a phased approach is prudent. |
| **Overall recommendation** | **Proceed with phased rollout** — the likely benefit outweighs the risk, but verify as you go. |

**Rationale**: The statistical evidence is strong (p < 0.001), the effect is consistent across model specifications, and the direction is favorable. However, the modest effect size, baseline group differences, and limited follow-up period argue for caution. A phased rollout allows the cooperative to capture potential benefits while building stronger evidence before full commitment.
