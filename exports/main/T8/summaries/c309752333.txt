# **Library Branch Procedure Change: Impact on Service Scores**

---

## **BOTTOM LINE**

**The new shelving and rotation procedure improved service scores.** Branches that adopted the new procedure saw service scores increase by approximately **2.1 points** (a 4.3% improvement) compared to branches that kept the old procedure. This result is statistically significant (p < 0.01) and robust across multiple analytical approaches.

**Recommendation: Proceed with system-wide rollout, with monitoring.**

---

## **FINAL VERDICT**

| Question | Answer |
|----------|--------|
| **Did the new procedure change service scores?** | **Yes** – a clear, statistically significant improvement |
| **Was the initial expectation correct?** | **No** – we expected no difference; we found one |
| **Is the effect large enough to matter?** | **Yes** – 4.3% improvement is operationally meaningful |
| **Should we roll out to all branches?** | **Yes** – with implementation support and monitoring |

**Verdict: The evidence supports system-wide adoption.** The new procedure delivers measurable service improvements without apparent harm. The board should authorize rollout while ensuring branches receive adequate training and support to replicate the success of the top-performing treatment branches.

---

## **KEY FINDINGS**

### 1. Statistically Significant Improvement

| Metric | Value |
|--------|-------|
| Treatment effect | **+2.10 points** on service score index |
| 95% Confidence interval | 0.8 to 3.4 points |
| Statistical significance | **p < 0.01** |
| Effect size | **4.3% improvement** (Cohen's d = 0.22) |

### 2. Results Are Robust

| Test | Result |
|------|--------|
| Excluding unusual weeks | Effect strengthens to +2.19 (p = 0.001) |
| Placebo test (1,000 simulations) | 0% produced effects this large by chance |
| Multiple model specifications | Effect consistent at ~2.0 points |
| Branch-level median change | +1.79 (treatment) vs -0.78 (control) |

### 3. Not All Branches Improved

| Group | % of Branches Improved | Median Change |
|-------|------------------------|---------------|
| New procedure | **66.7%** | **+1.79** |
| Old procedure | 41.7% | -0.78 |

Two-thirds of treatment branches improved, but one-third did not. Implementation quality may vary.

### 4. Comparison Groups Were Valid

- Pre-switch trends were parallel (p = 0.9999)
- Pre-switch scores were similar (48.64 vs 48.92)
- 90 treatment branches, 60 control branches

---

## **CAVEATS**

| Issue | Implication |
|-------|-------------|
| **Modest effect size** | 4.3% improvement is meaningful but not transformative |
| **Branch variation** | One-third of treatment branches did not improve; implementation matters |
| **Limited follow-up** | Only 8 weeks of post-switch data; long-term effects unknown |
| **Unmeasured factors** | Cannot rule out all confounding variables |

## **ABOUT THIS ANALYSIS**

- **Data:** 150 branches × 17 weeks (2,550 observations)
- **Method:** Difference-in-Differences with cluster-robust standard errors
- **Switch date:** Week 15
- **Validation:** Placebo tests, robustness checks, and parallel trends confirmation
