# **MEMORANDUM**

**TO:** Library Cooperative Board  
**FROM:** Data Analysis Team  
**DATE:** November 2025  
**SUBJECT:** Impact of New Branch Rotation and Shelving Procedure on Service Scores

---

## **Bottom Line**

The data shows the new procedure **improved service scores by approximately 2 points**. This contradicts the original expectation that the change would make no difference. The effect is statistically significant but modest in practical terms. We recommend **proceeding with rollout, with continued monitoring**.

---

## **Key Findings**

### **The Numbers**

| | Before Switch | After Switch | Change |
|---|---|---|---|
| **Branches with new procedure** | 52.2 | 53.4 | +1.2 |
| **Branches with old procedure** | 48.7 | 48.0 | −0.7 |
| **Net effect (DiD estimate)** | | | **+1.9** |

### **Statistical Assessment**

| Metric | Value | Interpretation |
|--------|-------|----------------|
| Effect estimate | +1.91 points | Modest improvement |
| 95% confidence interval | [0.83, 2.99] | Does not include zero |
| p-value | 0.0005 | Statistically significant |
| Effect size | 0.19 standard deviations | Small-to-moderate |

### **Important Caveats**

1. **Selection bias concern**: Branches chosen to switch scored 3.5 points higher than control branches even before the change. They may have been better-managed branches overall.

2. **Pre-trend variability**: The treatment-control gap fluctuated before the switch (ranging from 1.8 to 4.9 points), though statistical tests found no significant differential pre-trends.

3. **Control group decline**: Non-switched branches declined slightly (−0.75 points). The analysis assumes switched branches would have declined similarly without treatment.

---

## **Recommendations**

| Priority | Action |
|---|---|
| **1** | **Proceed with rollout** to remaining 60 branches |
| **2** | **Set clear success metrics** (e.g., maintain ≥1.5 point improvement) |
| **3** | **Evaluate after 3 months**—be prepared to adjust if effects don't materialize |
| **4** | **Document implementation details** to identify best practices |

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| **Did the procedure change service scores?** | **Yes** — the data rejects the "no difference" hypothesis |
| **Is the effect statistically reliable?** | **Yes** — p < 0.001, confidence interval excludes zero |
| **Is the effect large enough to matter?** | **Modestly** — about 0.2 standard deviations; meaningful but not transformative |
| **Should we roll out system-wide?** | **Yes, with monitoring** — likely benefit, unlikely harm, but verify effects persist |

**Bottom line on the bottom line:** The original expectation—that this change would make no difference—was **wrong**. The new procedure does improve service scores. However, the improvement is **modest**, not dramatic. Roll out, but keep watching the numbers.

---

**Data source:** branches.csv (2,550 observations, 150 branches, weeks 6–22)  
**Analysis method:** Difference-in-differences with cluster-robust standard errors and branch/week fixed effects
