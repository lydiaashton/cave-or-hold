# Board Summary: Evaluation of New Branch Stock Rotation Procedure

**Date:** November 2025  
**Prepared for:** Library Cooperative Board  
**Analysis Period:** Weeks 6–22 (17 weeks of data)

---

## Bottom Line

The new stock rotation and shelving procedure shows a **positive effect** on service scores, but the evidence is **not statistically definitive**. Branches using the new procedure improved by approximately **2 points** (4% gain) while control branches declined slightly. There is a **94.6% probability the effect is genuinely positive**, and **no evidence of harm**.

**Verdict: Proceed with phased rollout.** The balance of evidence favors adoption, but continued monitoring is essential to confirm the effect at scale.

---

## Key Findings

### What We Measured

| Group | Branches | Before Switch | After Switch | Change |
|-------|----------|---------------|--------------|--------|
| **New Procedure** | 20 | 47.52 | 48.95 | **+1.43** |
| **Old Procedure** | 14 | 49.28 | 48.81 | **−0.47** |
| **Net Effect** | — | — | — | **+1.90** |

### Statistical Results

| Metric | Value |
|--------|-------|
| Estimated improvement | +1.93 points |
| 95% confidence interval | −0.4 to +4.3 points |
| P-value | 0.11 |
| Probability effect is positive | 94.6% |
| Effect size (Cohen's d) | 0.20 (small-to-moderate) |

### What This Means

1. **The effect points in the expected direction.** Treatment branches improved; control branches did not.
2. **Statistical certainty is limited.** The 95% confidence interval includes zero, so we cannot rule out no effect.
3. **The odds favor a real benefit.** There is a 94.6% probability the true effect is positive.
4. **No harm detected.** Service scores did not decline in treatment branches.

## Final Verdict

### ✅ APPROVE PHASED ROLLOUT

**Rationale:**

| Factor | Assessment | Weight |
|--------|------------|--------|
| Direction of effect | Positive | ✓ Favors action |
| Statistical significance | Not met (p=0.11) | ⚠ Caution |
| Probability of benefit | 94.6% | ✓ Favors action |
| Risk of harm | None detected | ✓ Favors action |
| Effect size | ~4% improvement | ✓ Meaningful |
| Implementation cost | To be assessed | ⚠ Unknown |

**Decision:** The evidence is **suggestive but not conclusive**. Given the high probability of benefit, absence of harm, and modest effect size, a **phased rollout** is the prudent course. This balances the opportunity to improve patron service against the risk of scaling a procedure whose effect remains uncertain.

## Technical Appendix

**Methodology:** Difference-in-differences regression with branch fixed effects, controlling for staffing levels and visitor traffic. Standard errors clustered at branch level.

**Data:** 578 observations (34 branches × 17 weeks)

**Key assumption:** Parallel trends—treatment and control branches would have followed similar trajectories absent the intervention. Pre-switch trends support this assumption.

**Limitations:**
- Only 8 weeks of post-switch data
- High week-to-week variability in service scores
- Implementation fidelity not measured
