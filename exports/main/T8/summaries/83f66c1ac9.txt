# **Board Memorandum**

**To:** Library Cooperative Board of Directors  
**From:** Data Analysis Team  
**Subject:** Evaluation of New Branch Rotation and Shelving Procedure

---

## **Bottom Line**

**Recommendation: Approve system-wide rollout.**

The new procedure **improved service scores by approximately 2 points (4%)**. This finding was unexpected—the analysis was designed to detect any change, and we anticipated no effect. However, three independent analytical methods all confirm the same result with high statistical confidence (p < 0.01). The evidence supports expanding the procedure to all 150 branches.

---

## **Final Verdict**

> **The new rotation and shelving procedure should be adopted cooperative-wide.**
>
> The data are clear: branches that switched saw meaningful service score gains that cannot be explained by chance, staffing changes, or visitor volume. While we entered this analysis expecting no effect, the evidence now compels a different conclusion. Delaying rollout would deny patrons at 60 branches the benefit of improved service.
>
> **Vote recommendation: Approve.**

---

## **Key Findings**

| Metric | Result |
|--------|--------|
| Service score improvement | **+2.1 points** |
| 95% Confidence Interval | **[0.86, 3.30]** |
| Statistical significance | **p = 0.002** |
| Branches studied | 150 (90 treatment, 60 control) |
| Study period | 17 weeks |

### **What Changed**
| Group | Before | After | Change |
|-------|--------|-------|--------|
| Switched branches | 48.0 | 50.6 | **+2.5** |
| Non-switched branches | 47.9 | 48.4 | +0.5 |
| **Net effect** | | | **+2.1** |

### **Why We Trust This Result**
1. **Parallel trends confirmed** — groups moved together before the switch (p=0.80)
2. **Multiple methods agree** — DID regression and branch-level analysis both show ~2-point effect
3. **Confidence interval excludes zero** — we can rule out "no effect" with 95% confidence
4. **Controls don't change result** — effect holds accounting for staffing and visits
