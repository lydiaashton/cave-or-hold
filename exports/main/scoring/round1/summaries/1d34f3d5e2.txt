# **Library Branch Procedure Change: Impact on Service Scores**

**To:** Library Cooperative Board  
**From:** Data Analysis Team  
**Date:** November 2026  
**Subject:** Evaluation of New Shelving and Rotation Procedure

---

## **Bottom Line**

The new shelving and rotation procedure is associated with a **modest improvement in service scores of approximately 2 points** (on a scale where the average branch scores about 50). However, this effect is **not statistically significant at conventional levels** (p ≈ 0.09), meaning we cannot rule out that the observed improvement occurred by chance. The evidence is suggestive but not conclusive.

**Recommendation:** Proceed with a phased rollout while continuing to monitor results.

---

## **Key Findings**

### **Study Design**
| Element | Details |
|---------|---------|
| Branches studied | 34 total (20 treatment, 14 control) |
| Observation period | 17 weeks (weeks 6–22) |
| Switch date | Week 15 |
| Method | Difference-in-differences |

### **Results**
| Metric | Value |
|--------|-------|
| Estimated treatment effect | **+1.9 to +2.2 points** |
| Statistical significance | **p = 0.085** (marginally significant) |
| 95% Confidence interval | **−0.3 to +4.6 points** |
| Baseline average score | ~50 points |

### **Interpretation**
- Branches using the new procedure saw service scores increase by about **2 points more** than branches using the old procedure
- This represents roughly a **4% improvement** relative to baseline
- The effect is in the **positive direction** (higher scores are better)
- However, the confidence interval includes zero, so we **cannot be certain** the new procedure caused the improvement

### **Validity Checks**
✓ **Parallel trends satisfied:** Before the switch (weeks 6–14), treatment and control groups showed stable, parallel trends in service scores

✓ **No pre-existing differences:** Event study analysis shows no significant differences between groups in any pre-switch week

✓ **Results robust:** Findings hold when controlling for staffing levels and visitor traffic

- **Controls:** Staffing index, visits index (results robust to inclusion)
