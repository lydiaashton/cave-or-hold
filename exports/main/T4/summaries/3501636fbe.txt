# **Board Memorandum**

**To:** Library Cooperative Board  
**From:** Data Analysis Team  
**Date:** November 15, 2026  
**Subject:** Evaluation of New Branch Rotation and Shelving Procedure

---

## **Bottom Line**

The new rotation and shelving procedure **improved service scores by approximately 2.3 points** (a 5% gain). This result was unexpected—we anticipated no measurable effect—but the data are clear and statistically robust. **We recommend proceeding with system-wide rollout.**

---

## **Key Findings**

### **The Evidence**

| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| Branches keeping old procedure | 48.8 | 51.0 | +2.2 |
| Branches adopting new procedure | 48.1 | 52.6 | +4.5 |
| **Effect attributable to new procedure** | | | **+2.3** |

- **Statistical confidence:** p < 0.001; 95% confidence interval is 1.1 to 3.7 points
- **150 branches** studied over 17 weeks (9 weeks before, 8 weeks after)
- **90 branches** adopted the new procedure; **60 branches** maintained the old procedure

### **Why We Trust This Result**

1. **The comparison is valid.** Both groups followed nearly identical trends before the switch. The divergence appeared only after week 15, when the new procedure was implemented.

2. **The effect is consistent.** Treatment branches outperformed control branches in all 8 post-switch weeks, with the gap widening from +0.4 points (week 15) to +2.6 points (week 22).

3. **The result is robust.** The 2.3-point effect holds after controlling for staffing levels, visitor volume, and inherent differences between individual branches.

4. **The methodology is sound.** We used a difference-in-differences design—the standard approach for evaluating policy changes when random assignment is not feasible.

---

## **What This Means**

We entered this evaluation expecting no change. The data tell a different story: **the new procedure genuinely improves service quality.** This is welcome news. It means:

- Patrons at branches using the new procedure experience measurably better service
- The operational change delivers value beyond any implementation costs
- There is clear justification for extending the procedure to all branches

## **Appendix: Technical Notes**

- **Method:** Difference-in-differences regression with branch fixed effects
- **Standard errors:** Clustered at the branch level
- **Data:** 2,550 observations (150 branches × 17 weeks)
- **Outcome measure:** Service score index (branch average ≈ 50; higher is better)
