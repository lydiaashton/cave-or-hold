# **MEMORANDUM**

**To:** Board of Directors, Library Cooperative  
**From:** Data Analysis Team  
**Date:** Analysis based on 17 weeks of branch data (weeks 6-22)  
**Subject:** Evaluation of New Branch Stock Rotation Procedure  

---

## **Bottom Line**

**The new procedure significantly improved service scores and should be rolled out system-wide.**

Branches that adopted the new procedure saw service scores increase by **1.8 points** compared to branches that kept the old procedure. This represents a **3.5% improvement**, is highly statistically significant (p < 0.001), and the effect is consistent across all analytical checks. We recommend approving immediate rollout to all remaining branches.

---

## **Key Findings**

### 1. Measured Impact

| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| Switched branches (425 branches) | 51.46 | 54.04 | +2.58 |
| Control branches (284 branches) | 51.21 | 51.96 | +0.75 |
| **Net Effect of New Procedure** | | | **+1.81** |

The treatment effect of **+1.81 points** has a 95% confidence interval of **1.26 to 2.36 points**, meaning we can be highly confident the true effect falls within this range.

### 2. Statistical Confidence

- **p-value:** < 0.001 (less than 0.01% probability this result occurred by chance)
- **Effect size:** 0.18 standard deviations (small-to-moderate practical significance)
- **Robustness:** Result holds across multiple model specifications with different controls

### 3. Validity Checks Passed

**Parallel Trends Assumption:** Before the switch (weeks 6-14), treatment and control branches tracked closely together with an average difference of only 0.25 points. This confirms the groups were comparable before the intervention, supporting causal interpretation.

**Visual Evidence:** The attached chart shows treatment and control branches following similar trajectories before week 15, then diverging afterward as the new procedure took effect.

### 4. Analysis Scope

- **709 branches** total (425 adopted new procedure, 284 retained old procedure)
- **12,053 branch-week observations**
- **17 weeks** of data (weeks 6-22), with switch occurring at week 15
- Controls included for staffing levels and visitor volume
