# **Board Summary: Evaluation of New Branch Rotation and Shelving Procedure**

---

## **Bottom Line**

The new procedure shows **promising but not definitive evidence** of improving service scores. Our best estimate indicates a **4.7-point improvement** (approximately 9% increase from the baseline of ~50), but this result is **marginally statistically significant** (p=0.051). We cannot confidently rule out either no effect or a meaningful improvement.

**Recommendation:** Do not proceed with immediate system-wide rollout. Instead, extend the pilot period to gather more data before making a final decision.

---

## **Key Findings**

### **Study Overview**
| | |
|---|---|
| **Design** | Difference-in-Differences |
| **Treatment Group** | 20 branches (switched to new procedure at week 15) |
| **Control Group** | 14 branches (kept old procedure) |
| **Observation Period** | 17 weeks (weeks 6-22) |
| **Total Observations** | 578 branch-week records |

### **Results Summary**

| Group | Before Switch | After Switch | Change |
|-------|--------------|--------------|--------|
| Control (old procedure) | 49.18 | 49.35 | +0.17 |
| Treatment (new procedure) | 49.95 | 52.03 | +2.08 |
| **Difference-in-Differences** | | | **+1.91** |

After controlling for branch-specific characteristics and week-to-week variation, our preferred model estimates the **true effect at +4.7 points** (95% confidence interval: 0.2 to 9.3 points).

### **Statistical Confidence**

| Metric | Value | Interpretation |
|--------|-------|----------------|
| Point Estimate | +4.7 points | Best guess of the true effect |
| P-value | 0.051 | Just above conventional significance threshold |
| 95% Confidence Interval | [0.2, 9.3] | Plausible range of the true effect |

**What this means:** There is suggestive evidence of improvement, but the data is not conclusive. The true effect could be as small as 0.2 points (negligible) or as large as 9.3 points (substantial).

---

## **Next Steps**

### **Immediate Actions**

1. **Extend the pilot by 8-12 weeks.** Additional data will narrow the confidence interval and provide a clearer answer about the procedure's effectiveness.

2. **Audit implementation at switched branches.** Verify that all 20 branches are following the new procedure consistently. Variation in implementation could be masking the true effect.

3. **Hold off on system-wide rollout.** Given the uncertainty, committing all 34 branches to the new procedure at this time carries unnecessary risk.

### **Decision Timeline**

| Timeframe | Action |
|-----------|--------|
| **Now** | Continue current pilot; monitor all branches |
| **8-12 weeks** | Re-analyze with additional data |
| **After re-analysis** | Make final rollout decision based on updated evidence |

### **Decision Criteria**

| If updated analysis shows... | Recommended action |
|-----------------------------|-------------------|
| Effect ≥ 4 points, p < 0.05 | Proceed with full rollout |
| Effect 2-4 points, p < 0.10 | Consider phased rollout |
| Effect < 2 points or p > 0.20 | Reconsider or revise the procedure |

---

## **Context for the Board**

### **Why the Uncertainty?**
- **Limited observation window:** Only 8 weeks of post-switch data
- **Natural variation:** Service scores fluctuate week-to-week due to factors beyond the procedure (staffing, visits, seasonal patterns)
- **Sample size:** 34 branches provides moderate but not definitive statistical power

### **Why This Matters**
- A **4.7-point improvement** would represent meaningful progress in service quality
- A **full rollout** involves training costs, operational disruption, and potential resistance if the procedure proves ineffective
- **Waiting for more data** minimizes the risk of adopting an ineffective procedure system-wide

---

## **Technical Appendix**

**Methodology:** Difference-in-Differences regression with branch and week fixed effects. Standard errors clustered at the branch level to account for within-branch correlation over time.

**Model Specification:**
```
service_score = β₀ + β₁(treated) + branch_fixed_effects + week_fixed_effects + ε
```

Where `treated` = 1 for switched branches in weeks 15-22, and 0 otherwise.

**Key Assumption:** Pre-treatment trends were parallel between treatment and control groups. Visual inspection of weeks 6-14 confirms similar trends before the switch.
