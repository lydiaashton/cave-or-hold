# **MEMORANDUM TO THE BOARD**

**Subject:** Evaluation of New Stock Rotation and Shelving Procedure  
**Date:** November 15, 2026  
**Prepared by:** Data Analysis Office

---

## **BOTTOM LINE**

**The new procedure improved service scores.** Branches that adopted the new stock rotation and shelving procedure achieved service scores **2.2 points higher** (approximately **4% improvement**) than branches that kept the old procedure. This effect is statistically significant and consistent across the post-switch period. 

**Recommendation:** Proceed with rolling out the new procedure to all branches.

---

## **KEY FINDINGS**

### **Study Overview**
| | |
|---|---|
| **Branches studied** | 150 total (90 switched, 60 control) |
| **Study period** | 17 weeks (weeks 6–22) |
| **Switch date** | Week 15 |
| **Method** | Difference-in-differences analysis |

### **Results**
| Metric | Value |
|--------|-------|
| **Treatment effect** | **+2.20 points** |
| **95% Confidence Interval** | 1.03 to 3.38 points |
| **Statistical significance** | p = 0.0003 |
| **Relative improvement** | ~4.4% above baseline |

### **Why We Trust These Results**

1. **Valid comparison:** Before the switch, both groups followed parallel trends (p = 0.88), meaning any post-switch difference can be attributed to the procedure change.

2. **Persistent effect:** The improvement was observed in all 8 post-switch weeks, not driven by a single outlier week.

3. **Robust to other factors:** The result holds after controlling for staffing levels and visitor volume.

4. **Clean data:** All 150 branches have complete data for all 17 weeks with no inconsistencies.
