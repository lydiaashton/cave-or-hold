# **Board Summary: New Branch Stock Rotation Procedure Evaluation**

---

## **Bottom Line**

**The new procedure significantly improved service scores.** Branches that adopted the new rotation and shelving procedure saw service scores increase by **2.1 points** compared to branches that kept the old procedure. This represents a **4% improvement** and is statistically robust (p < 0.001).

**Recommendation: Proceed with systemwide rollout.**

---

## **Key Findings**

### Study Overview
| | |
|---|---|
| **Total branches** | 709 |
| **Switched to new procedure** | 425 branches |
| **Kept old procedure** | 284 branches |
| **Data period** | Weeks 6–22 (17 weeks) |
| **Switch implemented** | Week 15 |

### Results
| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| Switched branches | 49.5 | 52.3 | +2.8 |
| Non-switched branches | 48.5 | 49.2 | +0.8 |
| **Net effect** | | | **+2.1** |

- **Effect size:** 2.1 points (95% confidence interval: 1.5 to 2.6)
- **Statistical significance:** p < 0.001
- **Relative improvement:** 4% over baseline

### Additional Findings
- The improvement is **consistent across branch types** — no evidence that staffing levels or visitor volume affects the benefit
- Results are **robust** to alternative model specifications and control variables
- Service scores are on a scale where the average branch scores ~50; higher is better

---

## **Next Steps**

1. **Approve systemwide rollout** to the remaining 284 branches using the old procedure

2. **Develop implementation timeline** — consider phased rollout to manage training and logistics

3. **Continue monitoring** service scores post-rollout to confirm effects persist at full scale

4. **Capture best practices** from the 425 early-adopter branches to inform training materials

5. **Conduct cost-benefit analysis** if the new procedure requires additional resources

---

*Analysis based on weekly service score data (weeks 6–22). Statistical model uses difference-in-differences estimation with cluster-robust standard errors by branch.*
