# **To: Library Cooperative Board of Directors**
# **From: Data Analysis Office**
# **Subject: Evaluation of New Stock Rotation Procedure**

---

## **Bottom Line**

**We cannot conclude the new procedure improved service scores.** While switched branches show higher scores after implementation, they were already on a stronger improvement trajectory before the switch. After accounting for this pre-existing trend, the data provides **no clear evidence** that the new procedure itself caused any improvement.

---

## **Final Verdict**

> **The new stock rotation procedure has NOT been proven effective.**
>
> The apparent 2-point improvement in service scores is attributable to pre-existing differences between branches, not the procedure change itself. **We do not recommend cooperative-wide rollout based on current evidence.**

---

## **Key Findings**

| Question | Answer |
|----------|--------|
| Did switched branches improve? | Yes, but so did control branches |
| Did they improve MORE than expected? | **No** — the gap increase matches pre-existing trends |
| Can we attribute gains to the new procedure? | **Not with confidence** |
| Statistical estimate (uncorrected) | +2.0 points (p < 0.001) |
| Estimated effect (accounting for pre-trends) | **Approximately zero** |

### **The Core Problem**

Branches selected for the new procedure were already outperforming the control group before the switch:

| Period | Gap (Switched − Control) |
|--------|--------------------------|
| Week 6 | -0.17 points |
| Week 14 | +1.97 points |
| **Pre-period trend** | **+0.29 points/week** |

If this trend continued naturally (without any procedure change), we would expect the gap to grow by **2.33 points** over the 8-week post period. The actual gap increase was **1.98 points** — slightly less than expected.

### **What This Means**

The standard analysis shows a "significant" 2-point effect, but this is likely **selection bias**, not a treatment effect. Branches chosen for the new procedure may have been:
- Better managed
- More motivated to improve
- Already implementing other improvements
- Systematically different in unobserved ways

---

## **Recommendations**

| Priority | Action |
|----------|--------|
| **High** | Do not expand rollout based on current evidence |
| **High** | Investigate why switched branches were already improving |
| **Medium** | Consider a randomized trial for future procedure changes |
| **Medium** | Gather qualitative feedback from switched branches on operational impacts |
| **Low** | Continue monitoring; reassess after 6 more months of data |

---

## **Conclusion**

The new procedure cannot be credited with improving service scores based on this analysis. The apparent gains reflect pre-existing differences between branches, not the procedure itself. Before wider adoption, we recommend either (a) a randomized controlled trial or (b) waiting for more data with a more rigorous evaluation design.

---

*Analysis based on 12,053 weekly observations from 709 branches. The parallel trends assumption required for causal inference is violated in this data. Questions? Contact the Data Analysis Office.*
