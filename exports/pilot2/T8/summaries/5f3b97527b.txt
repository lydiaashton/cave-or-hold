# **Evaluation of New Branch Stock Rotation Procedure: Impact on Service Scores**

**To:** Board of Directors, Library Cooperative
**Date:** November 2026
**Subject:** Analysis of New Shelving and Stock Rotation Procedure

---

## **Bottom Line**

**The analysis is inconclusive.** While branches using the new procedure showed greater improvement in service scores (+2.3 points), this result is **not statistically significant** (p = 0.11). The data cannot confirm whether the new procedure actually caused better service scores or whether the difference reflects random variation. **More data is needed before drawing conclusions or making rollout decisions.**

---

## **Final Verdict**

| | |
|---|---|
| **Verdict:** | **INCONCLUSIVE — Continue Monitoring** |
| **Evidence of benefit:** | Suggestive, but not proven |
| **Evidence of harm:** | None detected |
| **Recommendation:** | Maintain current approach; defer rollout decision |
| **Confidence level:** | Low — additional data required |

**In plain language:** The new procedure *may* improve service scores, but we cannot say so with confidence. There is no reason to stop using it, but there is also insufficient evidence to justify expanding it. Collect more data before making major decisions.

## **Key Findings**

### Study Overview
| Element | Detail |
|---------|--------|
| Branches evaluated | 34 total (20 new procedure, 14 old procedure) |
| Study period | 17 weeks (weeks 6–22) |
| Procedure switch | Week 15 |
| Post-switch data | Only 8 weeks |
| Analysis method | Difference-in-differences with branch controls |

### Service Score Results

| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| Control (Old Procedure) | 44.8 | 45.3 | +0.6 |
| Treatment (New Procedure) | 49.9 | 52.8 | +2.9 |
| **Estimated Effect** | | | **+2.3 points** |

### Why We Cannot Draw Firm Conclusions

| Issue | Implication |
|-------|-------------|
| **Not statistically significant** (p = 0.11) | Cannot rule out that the effect is zero |
| **Wide confidence interval** (-0.5 to +5.1) | True effect could be negative, zero, or positive |
| **Baseline differences** | Treatment branches started 5.1 points higher, suggesting systematic differences |
| **Limited post-switch data** | Only 8 weeks after the change |
| **No randomization** | Branches were not randomly assigned to switch |

### What the Data Does Show
- ✓ **No evidence of harm** — The procedure did not decrease scores
- ✓ **Parallel pre-trends** — Groups tracked similarly before the switch (supports analysis validity)
- ✓ **Positive point estimate** — If the effect is real, it's modestly beneficial (~5%)
