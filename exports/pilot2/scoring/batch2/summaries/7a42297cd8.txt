# **Board Memorandum**

**To:** Board of Directors, Library Cooperative  
**From:** Data Analysis Team  
**Date:** November 2026  
**Subject:** Evaluation of New Stock Rotation and Shelving Procedure

---

## **Bottom Line**

**The evidence indicates the new procedure improved service scores.** Branches that adopted the new procedure achieved service scores approximately **2.2 points higher** than comparable branches using the old procedure. The effect is statistically significant (p = 0.022), though the confidence interval suggests the true effect could range from modest (0.3 points) to substantial (4 points). **We recommend proceeding with broader implementation while continuing to monitor results.**

---

## **Key Findings**

| Metric | Result |
|--------|--------|
| Estimated effect on service score | **+2.16 points** |
| 95% Confidence interval | 0.32 to 4.00 points |
| Statistical significance | Yes (p = 0.022) |
| Relative improvement | ~4.5% above baseline |
| Branches studied | 34 (20 switched, 14 did not) |
| Analysis period | Weeks 6–22 (8 weeks before, 8 weeks after switch) |

**What the data show:**
- Before the switch (weeks 6–14), both groups tracked similarly, supporting a valid comparison
- After the switch (weeks 15–22), branches using the new procedure pulled ahead and maintained the gap
- The effect holds after accounting for staffing levels, visit volumes, and inherent branch differences

---

## **Final Verdict**

| Question | Answer |
|----------|--------|
| Did the new procedure improve service scores? | **Yes** — the data support a positive effect |
| Are we confident in this conclusion? | **Moderately** — statistically significant at 5% level, but not 1% |
| Is the effect large enough to matter? | **Yes** — approximately 4–5% improvement on a key performance metric |
| Should we expand the procedure? | **Yes** — evidence supports rollout, with continued monitoring |

**Bottom line on the bottom line:** This is the kind of result organizations act on. The effect is real, meaningful, and in the expected direction. It is not so overwhelming that we can ignore implementation quality or stop measuring, but it is strong enough to justify expanding the procedure across the cooperative.

---

## **Recommendations**

| Priority | Action |
|----------|--------|
| **High** | Proceed with rolling out the new procedure to remaining branches |
| **High** | Document implementation best practices from high-performing switching branches |
| **Medium** | Continue monitoring service scores to confirm gains are sustained |
| **Medium** | Gather staff feedback to understand which aspects of the new procedure drive improvements |
| **Low** | Conduct formal cost-benefit analysis if implementation costs are substantial |

---

## **Caveats**

- Analysis covers 8 weeks post-implementation; longer-term effects remain to be confirmed
- Some branches may see larger or smaller effects depending on local conditions
- Ongoing training and support may be needed to maintain gains

---

**Conclusion:** The data confirm the new procedure delivers the service score improvement we anticipated. The board can move forward with confidence in expanding this change across the cooperative.
