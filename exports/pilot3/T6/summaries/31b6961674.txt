# **Board Summary: New Branch Stock Rotation Procedure**

---

## **Bottom Line**

The new procedure shows a **positive signal but inconclusive evidence**. The best estimate is a **1.8-point improvement** in service scores, but the data cannot rule out no effect or even a small negative effect. With 94% probability the true effect is positive, but this falls short of the 95% confidence threshold typically required for definitive conclusions. **We recommend continuing the pilot to gather more data before deciding on a full rollout.**

---

## **Key Findings**

### **The Numbers**

| Group | Before Switch | After Switch | Change |
|-------|---------------|--------------|--------|
| Control (old procedure) | 47.7 | 46.5 | **−1.2** |
| Treatment (new procedure) | 50.6 | 51.3 | **+0.7** |
| **Estimated Effect** | | | **+1.8** |

### **What the Data Tells Us**

| Question | Answer |
|----------|--------|
| Best estimate of the effect? | **+1.8 points** |
| Is it statistically significant? | **No** (p = 0.11) |
| 95% confidence interval? | **−0.4 to +4.1 points** |
| Probability the effect is positive? | **~94%** |
| Could the true effect be zero? | **Yes** |
| Could the true effect be negative? | **Yes (slightly)** |

### **What This Means**

The data is **suggestive but not conclusive**:
- The point estimate (+1.8) is encouraging and aligns with expectations
- However, we lack sufficient data to distinguish a real effect from random variation
- The confidence interval spans from slightly negative to moderately positive
- More observations would narrow this range and provide clearer guidance

---

## **Why the Uncertainty?**

| Factor | Impact |
|--------|--------|
| Only 34 branches | Limited statistical power |
| Only 8 weeks post-switch | Short observation window |
| Natural score variation (SD ≈ 8.5) | Makes small effects hard to detect |
| Minimum detectable effect | ~1.4 points with current data |

The study was designed to detect effects of about 1.4 points or larger. The observed 1.8-point effect is in the range where more data would help confirm whether it's real.

---

## **Recommendations**

### **Primary Recommendation: Extend the Pilot**

| Action | Rationale |
|--------|-----------|
| Continue current pilot for 8–12 more weeks | Would roughly double post-switch observations |
| Keep both groups as currently assigned | Preserves the comparison needed for analysis |
| Re-analyze after additional data | Should achieve statistical significance if effect is real |

### **Alternative: Phased Rollout with Embedded Evaluation**

If operational priorities favor expansion:
- Roll out to additional branches in waves
- Treat each wave as a new cohort for analysis
- Continue measuring and comparing against original control branches
- Be prepared to pause if later waves show no effect

### **What We Do NOT Recommend**

- **Full immediate rollout** — Premature given the uncertainty
- **Abandoning the procedure** — The signal is positive, not negative
- **Declaring success** — The evidence doesn't support that conclusion yet

---

## **Decision Framework**

| Scenario | Recommended Action |
|----------|-------------------|
| Extended pilot confirms +1.5 to +2.0 effect with p < 0.05 | Proceed with full rollout |
| Extended pilot shows effect near zero | Re-evaluate procedure design |
| Extended pilot shows negative effect | Discontinue and investigate why |
| Operational need requires action now | Phased rollout with continued monitoring |

---

## **Conclusion**

The new procedure performed as hoped—the point estimate is positive and meaningful. However, the data does not yet provide the statistical confidence needed for a definitive system-wide decision. **Extending the pilot is the lowest-risk path to a clear answer.**

---

*Analysis based on 17 weeks of data from 34 branches (578 observations). Difference-in-differences regression with cluster-robust standard errors.*
