# **Board Memorandum**

**To:** Library Cooperative Board of Directors  
**From:** Data Analysis Team  
**Date:** November 2026  
**Subject:** Evaluation of New Branch Rotation and Shelving Procedure

## **Bottom Line**

**The new procedure produced a small but consistent improvement in service scores—contrary to our expectations.**

Branches using the new procedure scored **1.8 points higher** than expected based on control branch trends. This effect was **positive in every single post-switch week** and is statistically reliable. However, the magnitude is modest (about 3.5% of the average score).

**Recommendation:** The effect is positive with no identified downsides. Proceed with rollout, but frame expectations appropriately—this is a incremental improvement, not a transformation.

---

## **Key Findings**

### 1. The Effect Is Real and Consistent

| Metric | Value |
|--------|-------|
| Estimated treatment effect | +1.8 service score points |
| Statistical significance | p < 0.01 |
| 95% confidence interval | +0.6 to +2.9 points |
| Weeks with positive effect | **8 of 8** (100%) |

The fact that treatment branches outperformed control branches in **every post-switch week** is noteworthy. This consistency suggests the effect is genuine, not a statistical fluke.

### 2. But the Effect Is Modest

| Context | Value |
|---------|-------|
| Average service score | 50.4 points |
| Typical week-to-week variation | ~2.5 points |
| Typical branch-to-branch variation | ~8.0 points |
| **Treatment effect** | **+1.8 points** |
| Effect as % of mean | 3.5% |
| Effect in standard deviations | 0.18 SD |

**Interpretation:** The improvement is comparable to typical week-to-week fluctuation. It's meaningful but not dramatic.

### 3. Why We Didn't Expect This

The procedure change was operational (rotation and shelving), not directly service-facing. Possible explanations for the unexpected improvement:

- Staff spend less time searching for materials → more time assisting patrons
- Improved organization reduces patron wait times
- Staff morale/engagement increased with new procedures
- Unmeasured factor correlated with the change

We did not collect data to test these mechanisms.
