# **Board Memorandum**

**To:** Library Cooperative Board of Directors  
**From:** Data Analysis Team  
**Date:** November 2026  
**Subject:** Evaluation of New Branch Rotation and Shelving Procedure

---

## **Bottom Line**

**The new procedure improved service scores—and we did not expect it to.**

Branches that adopted the new rotation and shelving procedure achieved service scores **1.8 points higher** than would have been expected based on trends at branches using the old procedure. This represents a **3.5% improvement** over the cooperative average. The finding is statistically significant and robust across multiple analytical approaches.

**Recommendation: Proceed with cooperative-wide rollout.**

---

## **Key Findings**

### 1. The Numbers

| Metric | Value |
|--------|-------|
| **Estimated treatment effect** | +1.8 service score points |
| **Statistical significance** | p < 0.01 (99% confidence) |
| **95% confidence interval** | +0.6 to +2.9 points |
| **Improvement vs. baseline** | ~3.5% |
| **Branches in study** | 150 (90 treatment, 60 control) |
| **Observation period** | 17 weeks (weeks 6–22) |

### 2. What Changed

Service scores at treatment branches rose after implementing the new procedure, while control branch scores remained flat:

- **Treatment branches:** 50.1 → 51.7 (+1.6 points)
- **Control branches:** 49.9 → 49.7 (-0.2 points)
- **Net effect:** +1.8 points

### 3. Why We Trust This Result

| Validation Check | Result |
|------------------|--------|
| **Parallel pre-trends** | ✓ Treatment and control branches tracked together before the switch (p = 0.68) |
| **Fixed effects model** | ✓ Result holds when controlling for branch-specific characteristics |
| **Clustered standard errors** | ✓ Result holds when accounting for within-branch correlation |
| **Control variables** | ✓ Result holds when adjusting for staffing and visitor volume |
| **Effect persistence** | ✓ Positive effect observed in all 8 post-switch weeks |

### 4. Context

- The cooperative-wide average service score is **50.4 points**
- Typical week-to-week variation is about **9.5 points** (standard deviation)
- The 1.8-point improvement equals roughly **0.2 standard deviations**—a meaningful gain for an operational change that required no additional funding

---

## **Why This Matters**

This finding is notable precisely because **we expected no effect**. The new procedure was implemented as an operational efficiency measure, not a service-quality intervention. The fact that it nevertheless produced a measurable improvement in service scores suggests:

1. **Operational changes can have downstream benefits** we don't anticipate
2. **Evidence-based evaluation works**—without this analysis, we might never have known
3. **Low-cost improvements are possible**—this change required training and process adjustment, not new resources

---

## **Next Steps**

### Decision Required
**Approve cooperative-wide rollout** of the new rotation and shelving procedure to all 60 branches currently using the old procedure.

### Implementation Plan
| Action | Timeline | Owner |
|--------|----------|-------|
| Document procedure best practices from pilot branches | 2 weeks | Operations |
| Develop training materials | 3 weeks | Training |
| Phase rollout (15 branches per month) | 4 months | Operations |
| Continue service score monitoring | Ongoing | Data Team |

### Follow-Up Evaluation
- **3-month check-in:** Confirm effect persists at scale
- **6-month review:** Assess any operational challenges or unintended consequences
- **12-month report:** Full cost-benefit analysis and recommendation on any refinements
